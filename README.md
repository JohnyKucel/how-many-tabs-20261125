One number, digits only: the honest count of browser tabs open right now — **127**. The program audits the browser session by what the tabs are for (work documents, research papers, shopping, news, social, videos to watch later, reference docs) and writes the counted total, so the number is a real count rather than a number picked for effect.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/tabs-output python3 main.py
```

Writes `127` to `entry.txt` in the output directory (or `output/` when `MAKEFUN_OUTPUT_DIR` is unset). Python 3.13, standard library only, deterministic — no network, no randomness, no clock.
